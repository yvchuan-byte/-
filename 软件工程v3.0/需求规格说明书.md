# 智慧园区能耗与环境监测系统 v3.0 需求规格说明书

## 1. 迭代范围

本迭代实现实时处理与告警，在前序数据接入功能上增加事件去重后的状态更新、一分钟聚合、设备在线状态和阈值告警；同时提供错误输入检测及可重复运行的错误用例测试。

## 2. 功能需求

### FR-01 实时事件处理

通过队列消费遥测事件。仅有效且未处理过的事件进入遥测历史；重复 eventId 返回重复状态并且不重复聚合或触发告警。

### FR-02 设备在线状态

有效遥测更新设备的最近上报时间和在线状态。超过 30 秒未上报的设备显示为离线；停用设备保持离线。

### FR-03 一分钟聚合

按照事件时间按分钟分桶，并按设备与指标聚合均值、最小值、最大值、样本数和异常样本数。迟到超过 60 秒的事件标记为异常质量数据。

### FR-04 阈值告警

根据启用的设备级或全局规则对有效事件实时检测，支持大于、大于等于、小于、小于等于和区间条件。规则支持连续次数、严重级别和冷却时间。达到条件时创建告警；指标恢复后自动解除活动告警。管理员及运维人员可以确认告警。

系统预置功率、温度、湿度和 PM2.5 规则。默认规则可在 SQLite `alert_rule` 表中调整。

### FR-05 错误用例检测

拒绝并隔离非法 JSON/对象、缺失字段、额外字段、非法 UUID、设备或指标不存在、单位不匹配、布尔/非有限/超范围数值、无时区时间及超前当前时间 5 分钟以上的事件。每条错误记录保留原因和原始内容；批处理遇到错误后继续检测后续事件。

## 3. 非功能需求

- 使用 SQLite 持久化遥测、聚合和告警。
- 模拟器通过线程安全队列投递事件，数据库处理由 UI 主线程执行。
- 界面展示在线状态、聚合统计、告警和隔离错误。
- 不依赖第三方 UI 库或外部网络。

## 4. 验收标准

1. 重复事件不重复入库、聚合或告警。
2. 同一分钟同设备同指标的样本聚合值正确，迟到事件计入异常样本数。
3. 有效事件令设备上线，超过在线时限后设备转为离线。
4. 连续超阈值达到规则次数后创建告警；相同活动告警不重复创建；恢复后解除。
5. 未授权只读用户不能确认告警。
6. 错误输入被隔离并可在“错误用例检测”页面查看，不阻塞同批有效事件。
7. `python -m unittest discover -s tests -v` 全部通过。
