# v3.0 系统原型说明

桌面界面使用 Python 标准库 Tkinter，不依赖外部 UI 库。

## 页面

- **设备档案**：维护设备并查看在线/离线状态。
- **指标定义**：查看指标和允许范围。
- **数据接入**：启动/停止模拟器、导入 JSON/JSONL 并查看最近遥测。
- **实时处理**：查看处理数量、在线设备、活动告警、错误数量和一分钟聚合结果。
- **阈值告警**：查看规则触发记录；管理员及运维人员可确认未确认告警。
- **错误用例检测**：查看被拒绝的消息、检测时间和错误原因。

界面采用默认规则演示连续越限和恢复过程。自动化错误用例测试覆盖非法格式、非法数值、缺失/额外字段、无效设备/指标、单位错误、范围错误及超前事件时间。
