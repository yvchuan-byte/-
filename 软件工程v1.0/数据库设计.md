# v1.0 数据库设计

数据库文件：`energy_monitor.db`（SQLite，程序首次启动时自动创建）。

## sys_user — 系统用户

| 字段 | 类型 | 说明 |
|---|---|---|
| username | TEXT PRIMARY KEY | 登录名 |
| password_hash | TEXT NOT NULL | PBKDF2-HMAC-SHA256 密码摘要 |
| display_name | TEXT NOT NULL | 显示名称 |
| role_code | TEXT NOT NULL | ADMIN / OPERATOR / VIEWER |
| enabled | INTEGER | 是否启用 |
| created_at | TEXT NOT NULL | UTC 创建时间 |

## device — 设备档案

| 字段 | 类型 | 说明 |
|---|---|---|
| device_code | TEXT PRIMARY KEY | 设备编号 |
| device_name | TEXT NOT NULL | 设备名称 |
| device_type | TEXT | 设备类型 |
| area_code | TEXT NOT NULL | 所属区域 |
| location_desc | TEXT | 安装位置 |
| enabled | INTEGER | 是否启用 |
| created_at / updated_at | TEXT | UTC 创建/更新时间 |

## metric_definition — 指标目录

| 字段 | 类型 | 说明 |
|---|---|---|
| metric_code | TEXT PRIMARY KEY | 指标编码 |
| metric_name | TEXT NOT NULL | 指标名称 |
| unit | TEXT NOT NULL | 单位 |
| min_value / max_value | REAL | 允许取值范围 |
| enabled | INTEGER | 是否启用 |

## telemetry_event — 遥测事件预留表

| 字段 | 类型 | 说明 |
|---|---|---|
| event_id | TEXT PRIMARY KEY | 事件唯一标识 |
| device_code | TEXT NOT NULL | 关联设备编号 |
| metric_code | TEXT NOT NULL | 关联指标编码 |
| metric_value | REAL NOT NULL | 指标值 |
| unit | TEXT NOT NULL | 单位 |
| event_time | TEXT NOT NULL | 设备侧事件时间 |
| received_at | TEXT NOT NULL | 本地接收时间 |
| raw_payload | TEXT NOT NULL | 原始 JSON |

`telemetry_event` 为后续 Sprint 2 预留，本版不实现遥测写入或数据模拟。
