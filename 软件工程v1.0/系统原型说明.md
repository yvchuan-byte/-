# v1.0 系统原型说明

v1.0 桌面界面采用 Python 标准库 Tkinter，界面结构和设备/指标表格交互与“软件工程”主程序保持一致。启动入口为 [`main.py`](./main.py)，界面实现位于 [`desktop_app.py`](./desktop_app.py)。

目录中的 [`index.html`](./index.html) 保留为可选交互式网页原型，使用原生 HTML、CSS 和 JavaScript，不依赖外部 UI 库。

## 页面流程

1. **登录页**：用户名、密码、登录按钮和三类演示账号提示。
2. **设备档案页**：设备表格；具备写权限的角色可新增、编辑和启用/停用设备。
3. **指标定义页**：只读展示指标编码、名称、单位、范围和启用状态。
4. **顶部账号信息**：显示当前登录用户及角色。

## 界面范围边界

界面中不出现运行总览、数据模拟、历史数据、告警规则、数据质量、审计或用户管理页面，以保证界面仅对应 Sprint 1。
