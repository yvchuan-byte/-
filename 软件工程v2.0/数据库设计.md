# v2.0 数据库设计

数据库使用 SQLite，文件为 `energy_monitor.db`，首次启动时自动创建。v2.0 沿用 v1.0 的 `sys_user`、`device`、`metric_definition` 和 `telemetry_event`，并新增异常隔离表。

## telemetry_event — 遥测事件

| 字段 | 类型 | 说明 |
|---|---|---|
| event_id | TEXT PRIMARY KEY | 事件 UUID；用于去重 |
| device_code | TEXT NOT NULL | 设备编号 |
| metric_code | TEXT NOT NULL | 指标编码 |
| metric_value | REAL NOT NULL | 指标值 |
| unit | TEXT NOT NULL | 指标单位 |
| event_time | TEXT NOT NULL | 设备侧事件时间，UTC ISO 8601 |
| received_at | TEXT NOT NULL | 本地接收时间 |
| raw_payload | TEXT NOT NULL | 原始 JSON |

## ingest_error — 接入异常

| 字段 | 类型 | 说明 |
|---|---|---|
| error_id | INTEGER PRIMARY KEY | 自增编号 |
| raw_payload | TEXT NOT NULL | 原始输入或出错记录 |
| reason | TEXT NOT NULL | JSON 解析或数据校验失败原因 |
| created_at | TEXT NOT NULL | 本地记录时间 |

无效事件不会写入 `telemetry_event`；每条无效记录单独记入 `ingest_error`，不影响同批后续记录。重复的 eventId 返回 DUPLICATE，不新增遥测或异常记录。
