# v2.0 系统原型说明

v2.0 使用 Python 标准库 Tkinter 桌面界面，布局和基础档案交互沿用“软件工程”主程序风格，不加载 Layui 或其他第三方 UI 库。

## 页面

1. **登录**：沿用三种 v1.0 演示账号。
2. **设备档案**：查看、添加、编辑、启用或停用设备；只读用户不能写入。
3. **指标定义**：查看指标编码、单位和取值范围。
4. **数据接入**：启动/停止模拟器、设置采集间隔、导入 JSON/JSONL、查看队列处理状态和最近接收事件。

模拟器线程将事件放入线程安全队列，UI 定时取出并在数据库线程中处理，避免跨线程共享 SQLite 连接。

页面不包含告警、实时聚合、历史查询和 CSV 导出，这些功能留待后续迭代。
